# Dicționar Chinez - Român

Proiect destinat consultării și dezvoltării unei baze de date bilingve pentru limba chineză și limba română.

**Versiune online:** [https://wdavidmnt.github.io/dictionar-chinez-roman/](https://wdavidmnt.github.io/dictionar-chinez-roman/)

---

## Descriere

Acest depozit găzduiește baza de date a dicționarului și interfața web aferentă. Aplicația permite căutarea termenilor în chineză (având valabile caractere simplificate și tradiționale), Pinyin, engleză și română.

## Contribuții

Membrii comunității pot propune adăugări sau corecturi pentru termenii existenți direct din interfața web, prin intermediul opțiunii de editare asociate fiecărui cuvânt, care creează o sesizare (Issue) pe GitHub.

## Mențiune privind inteligența artificială

Inteligența artificială a fost utilizată exclusiv pentru crearea și structurarea paginii web dedicate distribuției și colectării contribuțiilor.
Nu există alte utilizări ale sale în acest proiect.
